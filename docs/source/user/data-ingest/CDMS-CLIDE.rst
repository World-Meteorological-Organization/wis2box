Using CLiDE
===========

`CLiDE <https://www.bom.gov.au/government-and-industry/government-sectors/indo-pacific-development/climate-and-oceans-support-program-in-the-pacific/climate-data-for-the-environment>`_
is developed by the Australian Bureau of Meteorology (BOM) to support the management and processing of climate data. 
It was specifically designed for Pacific Island countries and provides each country with a local, central database for meteorological records.

The CliDE developer team is working on an option to ingest data into wis2box, to be made available in a future release of CLiDE.
