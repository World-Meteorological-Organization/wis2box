Using ClimSoft
==============

`ClimSoft <https://climsoft.org/>`_ is a software suite for storing climatic data widely used by National Meteorological and Hydrological Services (NMHSs) of developing countries in Africa.

The ClimSoft developer team is working on an option to ingest data into wis2box, to be made available in a future release of ClimSoft.
