Using ADT by IRI/SEI
====================

The `Automatic Weather Station Data Tool (ADT) <https://iri.columbia.edu/our-expertise/climate/tools/adt/>`_ is a web-based application developed by the International Research Institute for Climate and Society (IRI) to facilitate the ingestion of weather station data into WIS2 Nodes.
